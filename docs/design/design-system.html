Goban

Sente's design system. The app is a board: agents place stones, the enclave draws the lines, and Monad purple marks the moment something happens on chain. Everything below is drawn in CSS for review; the tokens map one-to-one onto apps/mobile/src/ui/theme.ts. See it applied in the mockups.

Principles

Four rules. When a screen is unclear, one of these is being broken.

Purple is an event

Monad purple means an agent is acting or a block is landing. It is on the primary button because pressing it makes something happen, and it drains out of a ledger row once the block is final.

A face is a speaker

Bricolage when the app raises its voice, Geist when it talks, Newsreader italic when the agent talks, Geist Mono when the chain does. You know who said it before you read it.

Stones say what happened

Five ledger kinds, five stones. The shape carries the kind, so a scrolled ledger reads as a pattern: runs of trades, a refusal, a verdict.

Limits are drawn, not listed

A mandate is territory. Show how much of each limit is used and where the line is — the user should see that an agent is near its edge without doing arithmetic.

Stones

The ledger's vocabulary. Each entry is placed on a vertical board line and drops in with a 600ms overshoot, like a stone set down.

Deposit White stone. Capital entering the game — the only entry the agent didn't make.
Thesis Hollow ring. Intent, written before the move.
Trade Solid purple, glowing. A move on the board.
Held Ring behind a bar. The enclave refused to sign. Never red.
Verdict Half stone, mint or berry. What the move was worth.

Components

Stones are round, so anything you press is a pill. Surfaces are softly squared boards. No elevation; depth comes from the ground stepping lighter.

Agent sigils

A 4×4 corner of a goban with stones seeded from the agent id. Stable, unique, and no avatars to generate or moderate.

Motion

Three motions, each tied to something real. Reduced motion turns all of them off.

  • Place — a new ledger entry rises 6px and settles with a slight overshoot over 600ms. Entries arriving together stagger by 100ms.
  • Consensus — the ramp fills a third per consensus state, only between states the block actually reported (SEN-24's rule stands).
  • Breathe — the dot on a live status pill pulses on a 2.4s cycle. It's the only idle animation in the app, and it means "this agent is running right now".
